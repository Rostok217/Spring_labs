# Лабораторна робота №3 — Spring Framework

**Варіант №8 — «Деканат».** Проєкт продовжує лабораторну №2, використовує Spring Boot + Thymeleaf.

## Що змінено щодо ЛР №2

- `src/main/resources/templates/groups.html`: додано `th:switch` / `th:case` з трьома випадками (0, 1, кілька груп); `th:if` для таблиці та повідомлення про відсутність груп. Цикл `th:each` збережено.
- `src/main/java/com/example/spring2/service/GroupService.java`: видалено лише дубльований import.
- Інші компоненти та функціональність ЛР №2 збережені.

## Відповідність методичці

- **2.1 умовне відображення:** `groups.html` (`th:if`), `students.html` (`th:if`, в тому числі для порожнього списку).
- **2.2 вибір:** `groups.html` (`th:switch` і `th:case`).
- **2.3 цикл:** `groups.html` та `students.html` (`th:each`).
- **2.4 XSS:** динамічні текстові значення виводяться `th:text`, значення полів форм через `th:field`, пошукові поля через `th:value`; `th:utext` і вбудовування введених значень в JavaScript не використовуються. Ці механізми екранують небезпечні HTML-символи у відповідних контекстах. Це не замінює повного аудиту безпеки на випадок майбутніх змін.
- **2.5 автентифікація / авторизація:** не реалізовані, як дозволено умовою.

## Як запустити

Відкрийте папку проєкту в IDE з Java 17+ та Maven. Запустіть `Spring2Application.java` або у Windows з кореня проєкту `mvnw.cmd spring-boot:run`. Після запуску відвідайте:

- http://localhost:8080/groups — список груп, демонстрація `switch/case`;
- http://localhost:8080/students — список студентів, `each`, `if`, пошук;
- http://localhost:8080/beans — демонстрація бінів із лабораторної №2.

## Що показати викладачу

1. На `/groups` побачити повідомлення `Кількість навчальних груп: 3`.
2. Видалити дві групи — повідомлення зміниться на «одна навчальна група». Якщо видалити останню, буде повідомлення про відсутність груп і кнопка її додавання. **Зверніть увагу:** видалення групи видаляє студентів цієї групи.
3. Створити групу й студента, побачити додавання нового рядка в таблиці (`th:each`).
4. На `/students` пошукати неіснуюче прізвище та побачити повідомлення «Студентів не знайдено» (`th:if`).
5. Для демонстрації HTML-екранування можна створити групу з назвою `<script>alert(1)</script>`: на сторінці назва повинна відображатися **як текст**, а не виконуватися. Для додаткової впевненості перевірте це в браузері.

**Примітка:** дані зберігаються лише в пам’яті (`ArrayList`), після перезапуску застосунку відновлюються початкові записи.

**Перевірка:** структура й шаблони перевірені статично. Повноцінний запуск Spring Boot у середовищі створення архіву не проводився, тому працездатність потрібно додатково підтвердити запуском на ПК.
